# Bundles

Bundles you own on itch.io show up in your library, and each one opens in its
own page listing every game it contains.

From a bundle's page, you can:

* Search the bundle's games by title
* Sort them, and filter by platform, classification, or installed status
* Install any game directly from the list

Bundles also appear in the search bar's suggestions, alongside your games and
collections.
